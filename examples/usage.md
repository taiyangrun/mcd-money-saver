# 使用示例

## 示例 1：穷鬼单点

**用户**：预算25，到店，喜欢鸡肉，帮我算最划算的

**助手执行**：
1. `query-nearby-stores(beType=1, city="深圳市")` → 选最近门店
2. `query-meals(storeCode, orderType=1)` → 拉菜单
3. `available-coupons()` → 发现"麦麦省新人券"
4. `auto-bind-coupons()` → 领券
5. `query-store-coupons(storeCode, orderType=1)` → 确认可用
6. 组合候选 → `calculate-price` 逐套验证

**输出**：
```
🍔 麦门省钱方案（1人·到店·预算25元）

方案A（推荐）：麦香鸡 + 中薯 + 可乐
- 原价：11 + 13.5 + 9 = 33.5元
- 用券：新人满30减10 → 实付 23.5元 ✅ 预算内
- 省 10元，热量约 850kcal

方案B：麦乐鸡(5块) + 小薯 + 可乐
- 原价 28元 → 券后 18元
- 更便宜，但少个汉堡看你饿不饿
```

## 示例 2：双人拼单

**用户**：2个人，一个要牛肉一个要鸡肉，预算70

**助手执行**：同上流程，重点对比双人餐 vs 单点

**输出**：
```
🍔 麦门省钱方案（2人·拼单）

方案A（推荐）：双堡双人餐
- 原价 71 → 用"满60减15"券 → 实付 56元
- 人均 28元，比各点各的省 22元
- 分账：牛肉那位 30 / 鸡肉那位 26（含券分摊）

方案B：各点各的
- 板烧鸡腿堡套餐 32.5 + 麦香鸡套餐 30 = 62.5
- 用券后 52.5，但两个人吃不到分享的快乐（不是）
```

## 示例 3：一键领券

**用户**：帮我把能领的券都领了

**助手执行**：`available-coupons()` → 展示 → `auto-bind-coupons()` → `query-my-coupons()` 确认

**输出**：`✅ 已领取 5 张券：满50减10、第二份半价...（卡包共 8 张可用）`
